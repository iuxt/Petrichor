开始之前

你可能想知道。

需要联网或注册账户吗？

无需注册账户，本地音乐的扫描、浏览、播放和已有歌词的读取均可离线使用。搜索在线标签、歌词或封面时才需要联网。自动歌词和自动封面为独立的可选功能，默认关闭。

如何导入我的音乐？

打开 Petrichor，点击「添加音乐文件夹」，选择已有的音乐目录，等待扫描完成即可。应用通过 macOS 沙盒访问你选择的目录，日常播放不改变音频文件和文件夹结构。

可以使用已有的歌词文件吗？

可以。将歌词与音频放在同一目录，保持相同文件名，例如 Song.flac 与 Song.ttml。旁车文件按 TTML → KSC → LRC → SRT 的优先级读取，没有有效旁车歌词时再读取内嵌歌词。

支持哪些 Mac？首次安装需要注意什么？

需要 macOS 15 或更高版本，支持 Apple Silicon 和 Intel Mac。从 GitHub Releases 下载安装包，将应用拖入「应用程序」。当前自动发布的安装包未签名、未公证，首次打开可能出现 macOS 安全提示，请阅读对应版本的发布说明。

遇到问题，在哪里反馈？

请前往 GitHub Issues，附上 macOS 版本、应用版本和复现步骤。关于安装、格式与使用方式，也可以查看 项目文档。
